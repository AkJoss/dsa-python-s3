# 🧮 DSA Python — Semester 3

Coursework from **3rd semester** of **Software Development Engineering** (Ingeniería en Desarrollo de Software) at Universidad Tecmilenio.

**Data Structures and Algorithms** projects in Python — console demos, sorting benchmarks, and small games.

**Author:** José Alberto Rocha Munguía

---

## 📂 Contents

| Folder | What it is |
|---|---|
| `software-logic-portfolio/` | Short DSA demos (search, sort, stacks, queues, trees, recursion, …) |
| `sorting-algorithms/` | Bubble / insertion sort + timing benchmark |
| `memory-game/` | Memory matching game (pygame assets) |
| `galatsia/` | Space-shooter style pygame game |

---

## 🛠 Requirements

- Python 3.10+
- For games: `pygame` (Anaconda Python 3.13 works well on this machine)

```bash
# Anaconda (recommended here):
/opt/anaconda3/bin/python3 -m pip install -r requirements.txt

# Or system/venv:
python3 -m pip install -r requirements.txt
```

---

## 🚀 Run examples

```bash
# Portfolio script
cd software-logic-portfolio
python3 binary_search.py

# Sorting benchmark
cd sorting-algorithms
python3 sorting_benchmark.py

# Memory game
cd memory-game
python3 memory_game.py

# Galatsia (run from its folder so images/ and music/ resolve)
cd galatsia
python3 main.py
```
